# 真实修复与优化案例

这份表是检索入口，不替代源码和测试。版本表示证据出现的位置，不表示所有平台同时完成。E 编号见 [证据索引](evidence.md)。

| 问题/目标 | 已核实原因或机制 | 可复用修复与回归 | 证据 |
| --- | --- | --- | --- |
| 多端数据各自维护易漂移 | 官网已生成共用 catalog、正文、章节和离线资源 | 单一公开内容源；保留旧字段兼容，接口发布与客户端接入分开 | E4，网站 2026-11-08 起 |
| 正文变了但客户端不知 | 目录元数据不能代表正文字节版本 | 正文/章节 hash 向书目录/catalog/manifest 传播；相同源重建要确定性 | E4，#253 |
| API 新富文本被误认为全端支持 | 服务端 richText 为可选字段，iOS 仍读 blocks | 双轨兼容、逐端接入，合成复杂表格/脚注样本不冒充线上内容 | E4，#255 |
| 封面缺失或更新后仍旧图 | 独立封面、正文首图、随包旧映射和网络缓存不同源 | 校验对应 revision 首图；负缓存与失败分开；删图不复活旧映射 | E1，0.6.10 |
| 刷新或切语言后回到旧数据 | 异步旧请求最后完成 | 以写盘及 UI 提交前检查为目标；已检 discover 满足，catalog 顺序不同，逐路径测试乱序完成 | E1，0.6.10 |
| 导航只读旧安装包 | 早期版本没有独立在线目录层 | 在线/缓存/随包按语言分层；失败保持搜索分类；远端接口另验 | E2，0.6.1；E4 |
| 正文索引过期 | 索引与正文可独立更新 | 索引绑定 revision，失配降为标题摘要并披露覆盖 | E1/E2，0.6.7 |
| 图片下载过大 | 列表和原图采用同一资源会浪费 | 按显示密度选变体，保留 aliases/原图与失败回退 | E1/E4，0.6.8 |
| 切语言可能改变当前阅读上下文 | UI 语言和正在读的内容不是同一状态 | 全局设置同步；当前正文/读位/导航保留，后续目录切语言 | E1，0.6.10 |
| 返回后又开出空白页 | 同次触摸返回后继续激活入口 | 连续手势在确认方向时取消点击，单次只返回一次 | E2，0.5.7 |
| App 内网页边缘返回不一致 | WebView 点击延迟与手势竞争，网页历史和关闭混淆 | 外层容器接管已接受边缘触摸；先网页历史后关闭 | E2，0.6.0 |
| 关于我长文切换跳动 | 动态文案高度改变轨道，分散几何回调反复写状态 | 自然高度/连续正文、聚合几何、同一插值、短屏大字不吸顶 | E1/E2，0.6.2、0.6.5 |
| 阅读工具遮最后链接 | 整条底栏与浮按钮占位混用 | 分开视觉/命中/内容安全空间；测最后一行与大字 | E1，0.6.10；E5/E6 |
| 动效在不可见/后台仍运行 | 缺少可见性、活动状态和系统策略门控 | 卸载计时器、保留相位，减少动态效果静态化；不伪造耗电指标 | E2，0.5.9、0.6.6 |
| 启动动画可能卡住或重播 | 播放器回调、超时、前后台并发 | 单调时钟、首帧/总上限、generation、终态不可逆、可跳过 | E1/E2，0.6.3–0.6.4 |
| 音乐浮条意外展开 | 会话与保存偏好/导航滚动状态耦合 | 会话默认折叠；用户点击展开；回前台不自动展开 | E1，0.6.10 覆盖旧规则 |
| 音乐和朗读互抢 | 多播放器缺统一音频所有权 | 明确互斥与交接；朗读结束不自行恢复音乐 | E1/E2，0.6.6 |
| 隐藏工具后又立即出现 | 视口重排、惯性/程序滚动被当成输入 | 输入意图、位置、进度分开；正反阈值与顶部规则 | E5–E7 |
| TV 控件禁用/隐藏后丢焦点 | 当前焦点没有合法新归属 | 每状态指定方向出口、返回目标、隐藏前迁移 | E6 |
| 宣称离线但 TV 仍有网 | Wi‑Fi 关闭不排除 Ethernet/其他网络 | 系统默认网络为 none，再冷启与重启复测 | E6，模拟器证据 |
| 离线下载形成混合发布 | 章节/图片下载期间服务端版本变化 | staging，前后 releaseID 一致，包校验后再提交 | E5；旧目录替换回滚仍有限制 |
| macOS 新库被旧并发覆盖 | 下载开始时比较版本不足 | 提交前再比较当前库；数据库验证与元数据匹配 | E7 |
| macOS 字号变化整篇重载 | 页面身份与外观状态混用 | pageKey 独立，applyControls；token 约束过期进度/搜索结果 | E7 |
| 图文链接被错误变为看图 | 所有图片父链接一律重写 | 仅识别实际 viewer 锚点，保留业务文章链接 | E7 |
| 复制链接看似成功 | 测试只看按钮/Toast | 实际粘贴比较 canonical 文章/章节 URL | E5/E6 |
| 安装成功被称为已运行 | 设备锁定独立阻止启动 | 读版本、数据对照、启动分别记录，不重复安装 | E1，0.6.10 |
| 统计配置被称为已入库 | HTTP/配置不是 GA4 服务端证据 | 分配置、传输、接收、报表四层，保留缺口 | E5；跨端历史记录 |

## 可追溯演进，而非补造完整历史

- 0.3.4–0.5.3：归档保留多轮页面截图和 0.5.3 交接，涵盖运营概览、原生关于我、科研/动态/AI刊面、最近/收藏/导航/修悟/音乐。不为只有截图的每个早期版本虚构根因或测试通过数。
- 0.5.4–0.6.0：多语言命名区分、扫码、设置/长按面板、返回修复、肖像融合、栏目动效与入口矩阵。
- 0.6.1–0.6.8：导航同步、滚动几何、启动视频、音乐会话、全文索引、多尺寸图片与分栏。
- 0.6.9–0.6.10：阅读工具和链接、封面、语言菜单、音乐默认折叠、下拉刷新。
- Android 0.4.1 / TV 0.1.4 / macOS 1.1.1：各输入方式的阅读工具、回顶、复制链接、离线与焦点适配。数字不可直接比较为同一产品里程碑。

未重现或未量化的性能、耗电、读屏、商店发布、实体 TV、物理折叠屏、全端富文本接入，不列为已完成优化。
